# Dashboard Macro ☁️

Versão nuvem do Dashboard Macro. Um robô do GitHub Actions roda `dashboard.py --snapshot` a cada ~5 min, grava `quotes.json` e o GitHub Pages serve a página.

- **Página:** https://daniguidotc.github.io/dashboard-macro/
- **Ativos e blocos:** `config.json` (mesmo formato da versão local)
- **Rodar agora:** aba *Actions* → *Cotações* → *Run workflow*

A versão local (`python3 dashboard.py` no Mac) continua funcionando igual, com atualização a cada 15 s e edição pelo ⚙.
